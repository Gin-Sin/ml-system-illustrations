03 Keep these three ideas

THE TAKEAWAY
⌊t / B⌋

Separate order from location.

Token t belongs to logical block ⌊t / B⌋, at offset t mod B. The block table supplies its physical address.

∑ αᵢ vᵢ

Keep the same attention.

All valid keys participate in the same normalization. Physical pages are storage units; they do not create separate attention windows.

B − 1

Bound the unused tail.

A sequence’s final block wastes at most B − 1 token slots in this model. Shared blocks save space until a write needs a private copy.
